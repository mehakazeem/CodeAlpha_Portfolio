# 🚀 NovaPortfolio - Personal Portfolio Website

Welcome to my personal portfolio website created as part of the **CodeAlpha Web Development Internship** (Task 3: Build Your Own Portfolio Site).

## 🌟 Overview
NovaPortfolio is a modern, responsive, and interactive personal portfolio showcasing my projects, skills, and background in Frontend Development, Cybersecurity, and AI.

## 🛠️ Tech Stack
- **Frontend:** HTML5, CSS3, JavaScript (ES6+)
- **Icons & Styling:** Font Awesome, Custom CSS Grid/Flexbox
- **Hosting:** GitHub Pages / Netlify

## ✨ Features
- **Responsive Design:** Seamlessly adjusts across desktops, tablets, and mobile devices.
- **Futuristic Dark Theme:** Custom neon glowing aesthetic with interactive hover effects.
- **Projects Showcase:** Displaying key applications with links to GitHub and Live Demos.
- **Interactive UI:** Smooth scrolling, navigation, and modern hero elements.
